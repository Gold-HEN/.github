## Overview

GoldHEN is a Homebrew Enabler developed for Sony PlayStation 4 systems. It extends the console environment with additional system functionality, developer-oriented features, payload execution, and homebrew application support.

The software integrates several components into one environment, including debug settings, remote package installation, external storage support, plugin management, FTP services, and an integrated FPS counter.

GoldHEN also provides interfaces for external payloads and system-level extensions, making it a widely used component of the PlayStation 4 homebrew ecosystem.
